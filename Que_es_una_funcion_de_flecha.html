1. ¿Qué es una Función de Flecha?

Una función de flecha es una forma compacta y moderna de escribir funciones en JavaScript. Se llaman así por su sintaxis, que utiliza un símbolo que parece una flecha: =>.

¿Para qué se utilizan?
Se utilizan principalmente para simplificar el código. Son ideales cuando necesitamos funciones cortas que se pasan como argumentos a otras funciones (como en map, filter o eventos).

2. Anatomía y Sintaxis

Comparemos la estructura clásica con la moderna:

Función Tradicional

const sumar = function(a, b) {
    return a + b;
}

Función de Flecha

const sumarFlecha = (a, b) => {
    return a + b;
}

La magia del "Retorno Implícito"

Si la función solo tiene una línea, podemos eliminar las llaves {} y la palabra return.

const saludar = nombre => "Hola, " + nombre;

3. Diferencias Clave (Por qué usarlas)

Característica Función tradicional Función de Flecha
Sintaxis Larga y verbosa Corta y elegante
Palabra this Tiene su propio this Hereda el this del entorno
Hoisting SÍ (declaraciones) NO (actúa como variable)
Parámetros Requiere () siempre () opcionales si es solo uno

4. El Gran Beneficio: El valor de this

Las Arrow Functions no tienen su propio this. Ellas "miran hacia afuera" y usan el contexto del lugar donde fueron creadas. Esto las hace perfectas para trabajar dentro de objetos o clases sin perder la referencia al objeto original.

5. ¿Cuándo NO usarlas?

  • No las uses como métodos de objetos si necesitas acceder a otras propiedades mediante this.
  • No tienen el objeto arguments.

Ejemplo Práctico: Resumen total

// Tradicional
const precioFinalTradicional = function(precio) {
    return precio * 1.21;
}

// Flecha (Mucho más limpia)
const precioFinalFlecha = precio => precio * 1.21;

console.log(precioFinalFlecha(100)); // Resultado: 121

Diccionario de Términos (Glosario)

  • Arrow Function: Sintaxis introducida en ES6 para escribir expresiones de funciones de forma más corta.
  • Retorno Implícito: Característica de las funciones de flecha de una sola línea que devuelven el resultado sin usar la palabra clave return.
  • Contexto Léxico: Se refiere a que las funciones de flecha determinan el valor de this basándose en el ámbito donde se definen, no donde se ejecutan.
  • Método: Una función que es propiedad de un objeto.
  • Callback: Una función que se pasa a otra función como argumento para ser ejecutada más tarde.
