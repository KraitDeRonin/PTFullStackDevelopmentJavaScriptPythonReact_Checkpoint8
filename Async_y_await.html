¿Qué hacen async y await por nosotros?

Checkpoint 8 - Azúcar Sintáctico y Legibilidad

← Volver al inicio

Introducción

Si las Promesas fueron una revolución, Async/Await fue el regalo definitivo para los desarrolladores. Es, en esencia, "azúcar sintáctico": una forma de escribir código asíncrono para que se lea de arriba hacia abajo, como si fuera síncrono.

  • async: Palabra clave que define una función asíncrona. Siempre devuelve una promesa.
  • await: Solo se usa dentro de funciones async. Pausa la ejecución hasta que la promesa se resuelva.

¿Para qué se utiliza?
Para evitar el encadenamiento excesivo de .then() y .catch(), haciendo que el flujo lógico sea mucho más natural y fácil de seguir.

1. Ejemplo Práctico: De Promesas a Async/Await

[Diagrama:¿Qué hacen async y awayt por nosotros?]

Forma con Promesas (.then)

function pedirCafe() {
    hacerPedido()
        .then(cafe => {
            console.log("Recibido: " + cafe);
            return beberCafe(cafe);
        })
        .then(() => {
            console.log("Terminé mi café.");
        })
        .catch(error => {
            console.log("Hubo un error: " + error);
        });
}

Forma con Async/Await (Más natural)

async function procesoCafe() {
    try {
        // "Espera" a que el pedido esté listo antes de continuar
        const cafe = await hacerPedido(); 
        console.log("Recibido: " + cafe);

        await beberCafe(cafe);
        console.log("Terminé mi café.");
    } catch (error) {
        // Captura cualquier error del proceso
        console.log("Hubo un error: " + error);
    }
}

2. Beneficios de usar Async/Await

Legibilidad: El código se lee como un libro. No hay funciones anidadas que compliquen la vista.
Manejo de errores: Se utiliza el bloque try...catch, el estándar en casi todos los lenguajes.

⚠️ Riesgos y Consideraciones

Olvidar el try...catch: Si una promesa falla y no hay un bloque catch, el error puede detener procesos críticos.

Secuencialidad innecesaria: Poner await a tareas que podrían ir en paralelo (como pedir dos cafés a la vez) hará que el programa tarde el doble.

3. Cuadro Comparativo Final

Característica Promesa (.then) Async / Await
Sintaxis Encadenada (.then) Lineal (secuencial)
Manejo de errores .catch() try...catch
Claridad Media (anidamiento) Alta (limpia)
Contexto Cualquier sitio Requiere función async

Diccionario de Términos (Glosario)

  • Azúcar Sintáctico: Características de un lenguaje diseñadas para que el código sea más fácil de leer o escribir, sin cambiar su funcionalidad.
  • Try...Catch: Estructura de control que permite "intentar" ejecutar código y "atrapar" errores si algo sale mal.
  • Bloqueo de ejecución: En el contexto de await, se refiere a pausar la función actual sin congelar el resto de la aplicación.
  • Paralelismo: Ejecutar varias tareas al mismo tiempo para ahorrar tiempo (ej: usando Promise.all).
  • Función Asíncrona: Una función que devuelve implícitamente una promesa y permite el uso de await.
