Ejercicio 1: Bucle for

En este ejercicio, creamos un bucle for estándar para recorrer un arreglo de nombres e imprimirlos uno por uno en la consola. 

const miLista = ["velma", "exploradora", "jane", "john", "harry"];

for (let i = 0; i < miLista.length; i++) {
  console.log(miLista[i]);
}

Ejercicio 2: Bucle while

Aquí resolvemos el mismo problema pero utilizando un bucle while. Es fundamental gestionar correctamente el contador para evitar bucles infinitos. 

const miLista = ["velma", "exploradora", "jane", "john", "harry"];
let contador = 0;

while (contador < miLista.length) {
  console.log(miLista[contador]);
  contador++; 
}
