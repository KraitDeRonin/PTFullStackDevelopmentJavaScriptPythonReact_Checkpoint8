¿Cuáles son las diferencias entre const, let y var?

Checkpoint 8 - Gestión de Variables y Scope

Evolución de las variables

Históricamente, solo existía var. Pero a medida que las aplicaciones se volvieron complejas, var empezó a causar "bugs" (errores) silenciosos. Por eso, en 2015 (ES6), se introdujeron let y const para darnos un control total sobre nuestro código.

1. El concepto clave: El "Scope" (Alcance)

Es el "reino" donde una variable vive y es accesible:

  • Global Scope: Accesible desde cualquier lugar del script.
  • Function Scope: Solo accesible dentro de la función donde se creó.
  • Block Scope: Solo accesible dentro de un par de llaves { ... } (como en un if o un for).

2. Desglose de los tres tipos

A. var (El veterano)

Es la forma antigua. No respeta bloques y permite re-declaraciones, lo que puede causar desastres en proyectos grandes.

if (true) {
    var nombre = "Alex";
}
console.log(nombre); // Imprime "Alex" (¡A pesar de estar fuera del bloque!)

B. let (El estándar moderno)

Es la evolución de var. Respeta el alcance de bloque y es ideal para valores que cambiarán, como contadores.

let puntaje = 10;
puntaje = 20; // Permitido
// let puntaje = 30; // ERROR: No puedes re-declarar en el mismo bloque.

C. const (El guardián)

Para valores que no deben cambiar. Hace que el código sea predecible y seguro.

const PI = 3.1416;
// PI = 4; // ERROR: JavaScript no permite re-asignar una constante.

4. El "Hoisting": El riesgo invisible

El Hoisting es un comportamiento donde JavaScript "mueve" las declaraciones al principio. Con var, puedes usar la variable antes de crearla y obtendrás undefined. Con let y const, el programa lanza un error, obligándote a escribir código más limpio y ordenado.

Diccionario de Términos (Glosario)

  • Scope: El contexto o alcance actual de ejecución en el que los valores y las expresiones son "visibles".
  • Hoisting: Comportamiento de JS de elevar las declaraciones al inicio del contexto de ejecución.
  • Inmutabilidad: La propiedad de un objeto o variable cuyo estado no puede ser modificado después de su creación.
  • ES6 (ECMAScript 2015): La sexta edición del estándar ECMAScript que introdujo mejoras significativas a JavaScript.
  • Temporal Dead Zone (TDZ): El período entre el inicio del bloque y la declaración de una variable con let o const donde no se puede acceder a ella.
