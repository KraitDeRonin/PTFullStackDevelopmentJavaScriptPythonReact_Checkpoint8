1. ¿Qué es el Operador de Extensión?

Se representa con tres puntos consecutivos (...). Su función principal es "expandir" o "desparramar" los elementos de un contenedor (como un Array o un Objeto) para que puedan ser utilizados de forma individual.

[Descomponiendo Arrays y Objetos]

¿Para qué se utiliza?
Imagina que tienes una caja de piezas de LEGO (un Array). El operador de extensión es como volcar la caja sobre la mesa: ahora tienes todas las piezas sueltas y listas para combinarlas con otras o usarlas por separado.

1. Usos Principales con Ejemplos

A. Copiar Arreglos y Objetos (Sin "vincularlos")

En JavaScript, si haces listaB = listaA, creas una referencia, no una copia. El operador de extensión rompe ese vínculo.

const original = [1, 2, 3];
const copia = [...original]; // Crea una copia independiente

copia.push(4);
console.log(original); // [1, 2, 3] (Sigue igual)
console.log(copia);    // [1, 2, 3, 4]

B. Combinar (Concatenar) Datos

Es la forma más elegante de unir información de diferentes fuentes.

const basicos = ["rojo", "verde"];
const extra = ["azul", "amarillo"];

const todosLosColores = [...basicos, ...extra, "negro"];
console.log(todosLosColores); // ["rojo", "verde", "azul", "amarillo", "negro"]

C. Expandir Objetos

Muy útil para actualizar datos sin borrar los anteriores (sobrescribiendo propiedades específicas).

const usuario = { nombre: "Luis", edad: 30 };
const usuarioActualizado = { ...usuario, ciudad: "Bilbao", edad: 31 };

console.log(usuarioActualizado); 
// { nombre: "Luis", edad: 31, ciudad: "Bilbao" } -> La edad se sobrescribió

2. Diferencia Crucial: Spread vs. Rest

Ambos usan ..., pero funcionan en sentidos opuestos:

  • Spread (Extensión): Saca los elementos de una caja (vuelca la caja).
  • Rest (Resto): Recoge elementos sueltos y los mete en una caja. Se usa en parámetros de funciones.

⚠️ Riesgos y Consideraciones

Copia Superficial (Shallow Copy): Solo copia el primer nivel. Si tienes objetos anidados, la copia profunda seguirá vinculada por referencia.

Orden de escritura: En los objetos, el orden importa. Las propiedades declaradas después del operador ... sobrescribirán a las del original.

Diccionario de Términos (Glosario)

  • Operador Spread: Sintaxis que permite expandir iterables (como arrays) en lugares donde se esperan múltiples elementos.
  • Referencia: Dirección de memoria donde se guarda un objeto; copiarla no crea un objeto nuevo, sino un acceso al mismo.
  • Concatenación: La operación de unir dos o más estructuras de datos en una sola.
  • Shallow Copy (Copia Superficial): Una copia que solo duplica la estructura de nivel superior, manteniendo referencias para objetos internos.
  • Inmutabilidad: Práctica de no modificar los datos originales, sino crear copias actualizadas de los mismos.
